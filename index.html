TV-ENVRandom env injection✓ passed

Environment variables are the simplest config channel into a sandbox. I generated two random key-value pairs, created the sandbox with them, and echoed them back from inside. The first attempt "failed" because my echo command had a bash variable-name parsing bug ($A_$B parses as one variable!) — the platform was fine, my quoting wasn't. Fixed with ${A}_${B} syntax and verified.
